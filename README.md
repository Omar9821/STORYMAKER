# Hikayati (Story Maker DZ)

Personalised children's story books: FastAPI + MongoDB backend, React frontend, Claude for the story, fal.ai for illustrations.

* Configuration: `backend/.env.example`
* Daily operation, monitoring, backups, privacy: `docs/OPERATIONS.md`
* Local end-to-end checks without any paid service: `python backend/tests/e2e/harness.py` then `python backend/tests/e2e/verify.py`
