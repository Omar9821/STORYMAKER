# دليل البائع (لك أنت) — بيع «حكايتي» على Flippa

## 1) السعر المقترح
- سعر الطلب المقترح: **4,900$** تقريباً، وأدنى سعر تقبله: **2,500$**. هذا تقدير مبني على أن المشاريع بلا إيرادات تُباع عادةً بين 1,000$ و15,000$، وليس ضماناً.
- Flippa قد تضع حداً أقصى لسعر الطلب للمشاريع بلا إيرادات (ذُكر أنه 9,999$) — راجع الصفحة عند الإدراج.
- ما يرفع السعر: موقع حي بحساب تجريبي، فيديو شرح، كتاب نموذجي حقيقي، وجود أول زبائن أو قائمة انتظار.

## 2) ما يجب تجهيزه قبل الإدراج
- [ ] رفع هذه النسخة إلى GitHub (مستودعك).
- [ ] نشر نسخة حية (Render + Netlify) وحساب تجريبي للأدمن بكلمة سر مؤقتة.
- [ ] كتاب نموذجي كامل (PDF) وصور شاشة وفيديو 1–2 دقيقة.
- [ ] حساب Flippa موثّق (هوية + وسيلة استلام الأموال).
- [ ] اسم نطاق (اختياري، يرفع قيمة العرض).

## 3) خطوات الإدراج
1. Sell → App/Website → اختر نوع «Starter / بلا إيرادات».
2. انسخ العنوان والوصف من FLIPPA_LISTING_EN.md (الجملة الأولى إلزامية كما هي).
3. ارفع الصور والفيديو والرابط الحي.
4. اختر باقة الإدراج (Startup بـ 149$ تعطي 90 يوماً — الأنسب).
5. فعّل الضمان Escrow ولا تنقل شيئاً قبل تأكيد الدفع.

## 4) قبل النقل
اتبع HANDOVER_CHECKLIST_EN.md. لا تعطِ أحداً كلمات سرك. غيّر كل المفاتيح.

## 5) ما سأفعله حين تربط Chrome
أملأ نموذج الإدراج وأنت مسجّل الدخول، وتضغط أنت «نشر» ودفع الرسوم. وأراجع العروض التي ترد وأساعدك في الرد والتفاوض.
